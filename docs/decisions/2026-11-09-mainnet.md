## Consequences

- The wallet checked 1Click's signed quote, so the deposit address it paid is tied to the vendor's Base address and the 2.0 USDC. That the 2.0 USDC arrived on Base is 1Click's doing; the evidence is the Base transaction, not anything the wallet verified.
- Both refusals of the attack are on record: the model's `DENY`, and the wallet's recipient list, which refused it first. The wallet checks the recipient list before the verdict, so this transaction doesn't show the verdict check refusing; [testnet's `GYQKNHhZ…`](https://testnet.nearblocks.io/txns/GYQKNHhZbhxrqNzi8rYs7wJaoD3Hif4LSKZVDFXYfn8P) does, with the list empty.
- The full-access key on the wallet is kept, so whoever holds it (William) could replace the contract. The checks a judge can run, the code hash against a reproducible build and `check-tx` on each transaction, hold for what the wallet did.
- Spent: 2.002807 USDC for 2.0 delivered (1Click's fee, about 0.0028 USDC), and under 0.1 NEAR in gas and USDC registrations. The wallet's 3.6 NEAR is its storage, recovered when it's deleted. Left in the wallet: 0.997193 USDC.
- After judging, the owner withdraws the USDC, and the wallet, owner, agent and vendor accounts are deleted.
